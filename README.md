# KKU Clash

KKU Clash เป็นเกมจำลองชีวิตนักศึกษาที่สร้างด้วย Godot ผู้เล่นจะต้องบริหารเวลา เข้าเรียน ทำกิจกรรม รับมือกับเหตุการณ์สุ่ม และเตรียมตัวสอบ เพื่อทำคะแนนรวมให้ได้สูงที่สุด

## ฟีเจอร์

- รองรับการเล่นคนเดียวและผู้เล่นหลายคนในเครื่องเดียว จำนวน 1–4 คน
- ตารางเรียนแบบสุ่ม
- เลือกคณะตอนสร้างตัวละคร: วิทยาลัยการคอมพิวเตอร์ ศึกษาศาสตร์ แพทยศาสตร์ หรือนิติศาสตร์
- ผู้เลือกคณะเรียนวิชาบังคับเฉพาะคณะ 1 วิชาและวิชาทั่วไปสุ่ม 3 วิชา ส่วนผู้ไม่เลือกคณะเรียนวิชาทั่วไปสุ่ม 4 วิชา
- วิชาเฉพาะคณะมีคำถาม 6 ระดับ ใช้ระบบเรียนและสอบเดียวกับวิชาทั่วไป คณะที่เลือกจะบันทึกกับเซฟและเปลี่ยนไม่ได้หลังเริ่มเกม
- สำรวจแผนที่มหาวิทยาลัยและทำกิจกรรมต่าง ๆ
- ระบบค่าสถานะผู้เล่น ได้แก่ การเรียน ความสุข พลังงาน ความหิว และเงิน
- เหตุการณ์สุ่มและตัวเลือกสถานการณ์
- ระบบบันทึกและโหลดเกม จำนวน 4 ช่องเซฟ
- ปรับระดับเสียงเพลงได้
- รูปแบบการแสดงผลหน้าจอ:
  - หน้าต่าง (Windowed)
  - เต็มจอ (Fullscreen)
  - ไร้ขอบ (Borderless)
- กระดานจัดอันดับคะแนนสูงสุด 10 อันดับภายในเครื่อง
- สรุปคะแนนและระดับผลการเล่นเมื่อจบเกม

## ความต้องการของระบบ

- Godot Engine 4.7 หรือใหม่กว่า
- รองรับการเล่นบน Windows

โปรเจกต์นี้ใช้ Forward+ renderer และ Jolt Physics

## เริ่มต้นใช้งาน

### ดาวน์โหลดเกม

ดาวน์โหลดเกมเวอร์ชันล่าสุดได้ที่ itch.io [คลิกที่นี่เพื่อดาวน์โหลด](https://iinuberry.itch.io/kku-clash)

### รันจากซอร์สโค้ด

1. ติดตั้ง Godot 4.7 หรือใหม่กว่า
2. Clone หรือดาวน์โหลด repository นี้
3. เปิดโฟลเดอร์โปรเจกต์ด้วย Godot
4. รอให้ Godot นำเข้าโปรเจกต์ หากมีการแจ้งเตือน
5. รันเกมผ่าน **Project > Run** หรือกด `F6`/`F5` จาก Godot editor

ฉากหลักที่ตั้งค่าไว้คือหน้าเมนูหลักของเกม

## วิธีเล่น

1. เลือก **New Game** จากหน้าเมนูหลัก
2. เลือกจำนวนผู้เล่น
3. ตั้งค่าผู้เล่นและตารางเรียน
4. สำรวจมหาวิทยาลัยและเลือกกิจกรรมอย่างรอบคอบ
5. บริหารค่าสถานะ เข้าเรียน ทำภารกิจ และจัดการเงิน
6. เล่นจนจบเกมแล้วเปรียบเทียบคะแนนรวม

คะแนนสุดท้ายคำนวณจากค่าสถานะผู้เล่น ภารกิจที่ทำสำเร็จ และผลการสอบ คะแนนที่สูงขึ้นจะได้รับระดับผลการเล่นที่ดีกว่า

## โครงสร้างโปรเจกต์

```text
asset/       รูปภาพ เพลง tiles และไฟล์ทรัพยากรอื่น ๆ
core/        ตัวจัดการระบบหลักและระบบที่ใช้ร่วมกัน
data/        ข้อมูลคำถาม สถานการณ์ และเหตุการณ์สุ่ม
dialog/      ข้อมูลตัวละครของ Dialogic
font/        ฟอนต์ที่ใช้ในส่วนติดต่อผู้ใช้
locations/   แผนที่มหาวิทยาลัย สถานที่ และการเคลื่อนที่ของผู้เล่น
ui/          เมนู หน้าต่างแจ้งเตือน HUD และหน้าสรุปผล
project.godot
```

ระบบสำคัญในโปรเจกต์:

- `core/script/Global.gd` — เก็บสถานะเกมและข้อมูลผู้เล่นที่ใช้ร่วมกัน
- `core/script/SaveManager.gd` — จัดการช่องเซฟและการโหลดเกม
- `core/script/AudioManager.gd` — จัดการเพลงและระดับเสียง
- `core/script/LeaderboardManager.gd` — จัดเก็บคะแนนสูงสุด 10 อันดับภายในเครื่อง
- `locations/new_map.gd` — ฉากหลักสำหรับการเล่นในแผนที่มหาวิทยาลัย
- `ui/endgame_ui.gd` — คำนวณคะแนนและแสดงหน้าสรุปผล

## ข้อมูลภายในเครื่อง

เกมจะจัดเก็บข้อมูลของผู้เล่นไว้ในโฟลเดอร์ `user://` ของ Godot:

- ไฟล์เซฟ: `user://saves/slot_1.json` ถึง `slot_4.json`
- การตั้งค่าเสียง: `user://audio_settings.cfg`
- การตั้งค่าหน้าจอ: `user://display_settings.cfg`
- กระดานจัดอันดับ: `user://leaderboard.json`

ไฟล์เหล่านี้จะถูกจัดเก็บไว้ในเครื่องของผู้เล่นและไม่ถูกเก็บไว้ใน repository
